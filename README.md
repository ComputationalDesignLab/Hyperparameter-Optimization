# Hyperparameter-Optimization
Hyperparameter optimization work done by Taeho Jeong during Master's degree (Fall 2022 ~ Fall 2024) 

There are two primary folders. The first one, HPO, contains all the code and data necessary for analytical functions. The second folder, Documentation, provides access to all the materials related to documentation. 
To view the generated documentation website, navigate to the docs folder, then to build, followed by HTML, and click on index.html after downloading the repository.
